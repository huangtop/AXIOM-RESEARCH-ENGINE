# V030.2 — Repository Contract Consolidation

## Purpose

V030.2 freezes ownership boundaries before structure.json migration and Real-110 metadata population.
It is deliberately **read-only**. It does not move, rename, delete, backfill or overwrite repository data.

## Product decisions

1. `data/universe` remains an accepted legacy universe source.
2. `data/company_registry` remains a staging/onboarding source.
3. production registry owns runtime company/security/business-description/official-classification outputs.
4. production financial, market and estimate layers own their respective runtime observations.
5. production build owns derived valuation outputs.
6. production research card owns the read-only frontend assembly contract.
7. `structure.json` remains human-maintained ground truth until V030.3 migrates it.
8. ingestion/research/industry/impact remain the canonical deep-research layers for core stocks.

## Contracts

The release defines contracts for:

- company identity
- security identity
- official classification
- business description
- financial facts
- market observations
- estimate observations
- valuation outputs
- frontend research cards
- investment classification (reserved for V030.3)
- deep research

## Audit behavior

The audit reports:

- missing canonical outputs
- empty accepted inputs
- invalid JSON
- multiple canonical path candidates
- contracts intentionally reserved for a future version

Missing outputs are diagnostics, not strict failures. This is necessary because the repository is being consolidated incrementally.
Strict mode fails only for invalid JSON or simultaneous canonical-path candidates, both of which can create ambiguous or unsafe builds.

## Validation

```bash
python -m pytest -q tests/test_repository_contracts.py
python -m axiom_engine.repository_contracts \
  --repository-root . \
  --output data/generated/repository_contracts/repository_contract_audit.json

python -m axiom_engine.repository_contracts \
  --repository-root . \
  --output data/generated/repository_contracts/repository_contract_audit.json \
  --strict
```

Then run the full suite:

```bash
pytest -q
```

## Expected result

The command should produce a JSON report. Empty `business_descriptions.json` and `official_classifications.json` are expected to appear as diagnostics until the Real-110 metadata completion release.

## Explicit non-goals

- no SEC backfill
- no structure.json migration
- no automatic classification
- no valuation model selection changes
- no frontend changes
- no Render deployment changes
